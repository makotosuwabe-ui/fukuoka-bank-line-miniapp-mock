# 福岡銀行 LINEミニアプリ Webモック

スマートフォンのブラウザで操作できる、福岡銀行のサービス申込を想定した非公式の試作画面です。銀行・LINEの公式サービスではありません。

## 操作

`index.html` を開くと利用できます。口座開設、来店予約、ローン、投資信託、相談から、入力・確認・受付完了まで操作できます。申込履歴と残高の表示設定は、利用中のブラウザの `localStorage` に保存されます。

表示される残高・借入情報・受付番号などは仮データです。入力内容は銀行に送信されません。実際の個人情報は入力しないでください。

LIFF、LINEログイン、本人確認、審査、決済、銀行APIは接続していません。
